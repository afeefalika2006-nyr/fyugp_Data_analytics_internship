Power BI was easier for creating dashboards and visual charts because I could drag and drop fields instead of writing code. Adding slicers, bar charts, and filters felt faster and more visual in Power BI. It was also easier to understand relationships between tables because the interface clearly showed the data model.
Python was easier for data cleaning and repetitive tasks. Using Pandas functions like groupby(), fillna(), and loops helped automate tasks that would require many manual clicks in Power BI. I also liked that Python allowed more control over the analysis and calculations.
I personally enjoyed Power BI more at the beginning because it was easier to see results quickly. Later, I started enjoying Python because solving problems with code felt satisfying and helped me understand how data analysis works internally. Writing functions and using loops made me feel like I was building solutions instead of only clicking options.
If I had to analyse data for a report to share with a teacher or manager, I would use both tools together. I would use Python for cleaning and analysing the data, then use Power BI to create interactive dashboards and visual reports because they are easier for others to understand.
